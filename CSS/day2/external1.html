External

External refers to something that is outside a system, device, or organization. In computer technology, external devices are hardware components connected to a computer from the outside to improve functionality and performance. Examples of external devices include a keyboard, mouse, printer, speakers, webcam, and external hard disk. These devices help users perform different tasks easily and efficiently. External storage devices are also useful for saving important files, transferring data, and creating backups. With the growth of technology, external devices have become faster, more portable, and easier to use in everyday life.

Id Selector

An ID selector in CSS is used to apply styles to a specific and unique HTML element. It is represented using the # symbol followed by the ID name. The ID selector helps developers design a single element differently from other elements on a webpage

Each ID value should be unique, meaning it should not be repeated for multiple elements in the same HTML document. For example, if a heading has an ID called header, it can be styled in CSS using #header. ID selectors are useful for creating unique styles and improving webpage design and organization.
